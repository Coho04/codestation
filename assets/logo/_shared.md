# Logo-Quellen

Handgezeichnete Vektoren, keine generierten Bilder. Vier Kandidaten, alle nach
denselben Regeln entworfen:

- **Ein Motiv, keine Szene.** Bei 16 px überlebt genau eine Form.
- **Keine Verläufe im Motiv.** Sie werden beim Verkleinern zu Matsch; Fläche
  und Kontur bleiben lesbar.
- **Monochrom-tauglich.** Wer die Farbe wegnimmt, muss das Zeichen noch
  erkennen — das ist der härteste Test für eine Silhouette.
- **Farben aus der App.** Hintergrund `#0a0a0a` (neutral-950), Akzent `#0ea5e9`
  (sky-500), Warnton `#fbbf24` (amber-400). Das Icon gehört sichtbar zur
  Oberfläche.
- **Squircle selbst gezeichnet.** macOS maskiert App-Icons nicht automatisch;
  die abgerundete Form muss Teil der Grafik sein, mit Rand ringsum.
